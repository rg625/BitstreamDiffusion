# Trajectory dynamics — SG divergence and CFG fix/break

**Zero GPU.** From the five `rb_traj` `.npz` files (64 problems × 256 logged rows,
stride 4, original steps 0–1020) plus existing per-problem outcomes. Figures:
`docs/report/fig/fig7`–`fig10`, regenerated by `docs/report/make_traj_figures.py`.

---

## 1. Executive result

**SG-prev w=2 and w=0.125 are qualitatively different failures, not one failure
at two strengths.** w=2 is a runaway that never recovers; w=0.125 ends in a state
statistically indistinguishable from baseline yet still answers wrong.

**The runaway is not "guidance overpowering the drift".** Both the guidance term
and the model's own drift inflate together — ‖g‖ by ~35× and ‖s‖ by ~14× relative
to baseline. The ratio rises because the numerator inflates *faster*, not because
the denominator collapses. And the state is measurably abnormal **~85 steps
before** the ratio ever crosses 1.

**The CFG fix/break comparison could not be run.** The 64-problem subset contains
**5 fixes and 2 breaks**. That is a sample-size failure, not a null result.

---

## 2. A. SG divergence timing

Change-points are detected against the baseline arm using a robust z-score
(median/MAD per step), requiring 5 consecutive logged rows (= 20 original steps).
The threshold for each feature was **calibrated leave-one-out on the baseline's
own 64 trajectories** so that ≤5 % of baseline trajectories flag — set by data,
not chosen.

| Feature | calibrated \|z\| | baseline false-alarm |
|---|---|---|
| bit_entropy | 5.50 | 3/64 |
| sat_lt_001 | 3.00 | 2/64 |
| x_norm | 2.75 | 2/64 |
| s_norm | 2.00 | — |

### Event ordering, SG-prev w=2 (all events fire in 64/64 trajectories)

| Event | median step | IQR |
|---|---|---|
| ‖s‖ anomaly | **88** | [80, 104] |
| ‖x‖ anomaly | **120** | [111, 132] |
| ratio > 1 | **172** | [152, 204] |
| saturation fails | **692** | [660, 717] |
| bit entropy fails | **764** | [740, 776] |

Paired within each trajectory (fraction where the row event precedes the column
event): ‖s‖ before ‖x‖ in **94 %**, ‖s‖ before ratio>1 in **100 %**, ‖x‖ before
ratio>1 in **89 %**, ratio>1 before saturation in **95 %**, saturation before
entropy in **94 %**. The ordering is highly consistent across trajectories, not
an artefact of averaging.

**The sequence is: state anomaly → ratio crossing → saturation failure →
entropy failure → degenerate tokens.** The guidance dose crossing unity is the
*third* event, not the first. This contradicts the natural reading of the
earlier aggregate observation ("divergence at step ~62 with ratio ~2.4"): the
ratio is a **late symptom**, and the earlier aggregate figure conflated a
population mean with a per-trajectory event.

### Is it numerator- or denominator-driven?

Median norms, each divided by the **baseline's own drift at the same step**:

| step | 88 | 172 | 500 | 764 |
|---|---|---|---|---|
| SG w=2 ‖g‖ | 0.46 | 1.86 | 11.9 | **34.9** |
| SG w=2 ‖s‖ | 1.04 | 1.47 | 6.89 | **14.4** |
| SG w=0.125 ‖g‖ | 0.008 | 0.042 | 0.46 | 0.56 |
| SG w=0.125 ‖s‖ | 1.00 | 1.00 | 1.02 | 1.03 |

At w=2 **both inflate by an order of magnitude** — this is a positive feedback
loop, not a collapsing denominator. A plausible reading, consistent with but not
proven by these data: guidance pushes the state off-manifold, the posterior then
sits further from the state so ‖D−x‖ grows, SG's consecutive-prediction
difference grows with it, and the loop closes. At w=0.125 ‖s‖ never leaves 1.00–1.03 —
no feedback, the state stays on-manifold.

### Recovery — the two scales differ in kind

| | peak ratio | recovered (final ratio < 0.5) | final entropy | final saturation |
|---|---|---|---|---|
| baseline | — | — | 0.0000 | 0.8008 |
| SG w=0.125 | 1.26 | **100 %** | **0.0000** | **0.7925** |
| SG w=2 | 9.76 | **0 %** | 0.0021 | 0.5298 |

**w=0.125 ends in a normal state.** Its final entropy and saturation match
baseline, and every trajectory recovers — yet accuracy is 0.109 against
baseline's 0.281. So the w=0.125 damage is **not** a trajectory pathology: the
dynamics look healthy at the end and the answer is simply wrong. That is failure
type **B** in the earlier taxonomy. w=2 is type **A/C**.

**Answering Q6 directly: no, they are not the same failure shifted.** One is a
terminal dynamical runaway; the other leaves the dynamics intact and changes the
answer.

## 3. B. CFG fix/break — not answerable at this sample size

| Group | n |
|---|---|
| FIX (baseline wrong → CFG right) | **5** |
| BREAK (baseline right → CFG wrong) | **2** |
| both correct | 16 |
| both wrong | 41 |

Baseline 18/64 correct, CFG 21/64, net +3.

Across nine features in three windows (early/mid/late), comparing per-problem
medians with a bootstrap on the FIX−BREAK median difference: **no comparison was
computable at n=2, and none of the descriptive gaps exceeds the between-problem
spread.** Reporting effect sizes from a two-trajectory group would be
meaningless, so none are quoted.

This is a **design shortfall, not a finding.** The 250-problem screen gave 14
fixes and 13 breaks, i.e. rates of ~5.4 % and ~5.2 %. Reaching ~20 per group
needs roughly **370 problems logged**, not 64. Trajectory logging is a verified
no-op and costs only storage, so the fix is to log every problem in any future
run rather than a prefix.

## 4. What is supported

1. SG-prev w=2 fails through an early, universal (64/64), tightly-timed state
   anomaly at step ~88, ~500 steps before the entropy/saturation collapse.
2. The event ordering state → ratio → saturation → entropy holds in ≥89 % of
   trajectories pairwise.
3. The runaway inflates guidance and drift *together*; it is not denominator
   collapse.
4. w=0.125 and w=2 are qualitatively different failure modes.
5. Guidance is near-orthogonal to the drift for every method
   (‖orth‖/‖g‖ ≥ 0.999), so direction does not distinguish the mechanisms.

## 5. What is NOT supported

1. **The universal stability-threshold hypothesis remains unsupported**, and is
   further weakened: within SG-prev w=2 the ratio crossing 1 is a *late symptom*
   preceded by the state anomaly. Nothing here rehabilitates it.
2. Max-ratio still does not separate correct from wrong trajectories within any
   method (previous pass: 0.097 vs 0.112 for CFG, 1.239 vs 1.264 for SG-0.125).
3. No trajectory signature distinguishes CFG's fixes from its breaks — **untested**,
   not disproven.
4. The feedback-loop reading of the runaway is a plausible mechanism consistent
   with the data, not a demonstrated causal chain.

## 6. Implications

The guidance study has reached the point where the remaining questions are about
**one mechanism (SG) failing in an interesting way**, not about whether guidance
helps. On the accuracy question the answer is settled at this operating point:
CFG is a near-null bidirectional perturbation, AG and SG are harmful.

The one genuinely novel mechanistic object here is the **SG runaway** — a
measurable positive-feedback instability with a reproducible event ordering. It
is, however, an instability in a method that does not work.

## 7. Recommendation

**Option C — freeze the guidance study.**

The CFG fix/break question is the only one a further guidance run could answer,
and it needs ~370 logged problems (~6 GPU-h) to produce a comparison that, on the
250-problem evidence, is most likely to show 14 fixes and 13 breaks with no
trajectory signature — i.e. to confirm a null we already have three independent
lines of evidence for (near-zero net delta, fix/break parity, no ratio
separation).

That is a poor use of 6 GPU-h against the open questions in representation
(logits/softmax vs score-matching) and temporal ordering, neither of which has
any evidence yet.

If a single guidance experiment were run anyway, the highest-value one is **not**
CFG confirmation but the **SG mechanism probe**: the feedback-loop reading
predicts that clamping ‖g‖ to a fixed fraction of ‖s‖ each step should prevent
the runaway entirely and convert w=2 from 0.000 back to roughly the w=0.125
regime. That is a sharp falsifiable prediction and ~2 GPU-h. But it tests a
method already established as harmful, so it is a curiosity, not a priority.
